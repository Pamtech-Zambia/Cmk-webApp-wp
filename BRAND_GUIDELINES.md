# CMK Baking - Brand Guidelines

## Brand Name
- **Official Name**: CMK Baking
- **Tagline**: Artisanal Baking
- **Full Description**: Handcrafted Excellence

## Color Palette
- **Primary Gradient**: Pink (#ec4899) → Orange (#f97316)
- **Secondary Gradient**: Orange (#f97316) → Yellow (#eab308)
- **Background**: Gradient from pink-50 via orange-50 to yellow-50
- **Accent**: Pink for highlights and CTAs

## Logo & Icon
- **Logo Text**: "CMK"
- **Logo Icon**: 🍰 (Cake emoji)
- **Placement**: Top-left in Sidebar, above headings

## Typography
- **Font Family**: Geist (sans-serif)
- **Headings**: Bold, gradient text (pink to orange)
- **Body**: Regular weight, dark gray (#1f2937)
- **Sizes**: Scale from mobile to desktop (5xl → 7xl)

## Emoji Usage
- 🍰 Bakery/products/brand icon
- 💌 Messages/wishes/communication
- 👥 Community/people
- ✨ Quality/premium/excellence
- 💝 Care/love/special occasions
- 🎉 Celebration/excitement

## Spacing & Layout
- **Sidebar Width**: 256px (w-64)
- **Max Content Width**: 1152px (max-w-6xl)
- **Padding**: Consistent spacing with Tailwind scale
- **Mobile First**: Design for small screens first
